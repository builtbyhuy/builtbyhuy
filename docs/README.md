# Huy's portfolio hub

Static English portfolio with three case pages, a Vietnamese owner guide and an original 1200 × 628 cover page. Serve this folder as the site root. All internal links support a repository subpath; no root-absolute asset path is used.

Target canonical URL: <https://builtbyhuy.github.io/builtbyhuy/>.

`cover.html` is designed for a 1200 × 628 browser capture. The inspected result is included as `assets/portfolio-featured.png`, which the home page uses as its Open Graph image.

- `index.html`: public selected work.
- `work/`: three readable cases with evidence links.
- `guide.html`: Vietnamese usage, presentation and editing guide.
- `sources.html`: readable public design sources, licenses and provenance.
- `DESIGN-NOTES.md`: actual sources, adaptation choices and licenses.
- `styles.css`, `script.js`, `assets/`: local implementation and assets.

The Before/After interaction updates actual example screenshots. Main content and navigation work without JavaScript.

See `VALIDATION.md` for checks actually performed. Source creation does not itself establish deployment.
