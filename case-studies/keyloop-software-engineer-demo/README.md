# Keyloop Software Engineer — application proof-of-value demo

This six-slide deck is a job-specific application demo for the public [Keyloop Software Engineer posting](https://jobs.lever.co/keyloop/6b9a1f9b-c3bc-4600-a346-8b3610c4f00c).

It shows how I would translate evidence from a real automotive service-workshop project into a bounded, testable service-event workflow:

- **Real evidence:** a six-month 2S Phúc Lợi project where I built a mini app to manage vehicle entries and exits using images.
- **Proposed role adaptation:** capture, validate, deduplicate, serve through an API boundary, and retain an audit trail.
- **Independent technical proof:** the [webhook-to-CRM reliability sample](https://github.com/builtbyhuy/webhook-crm-reliability-sample), which demonstrates HMAC validation, idempotency, conflict detection, bounded retries, and explicit failure handling with fictional input and a simulated CRM.

The deck separates existing work from proposed role fit. It uses no Keyloop internal data and makes no client production or performance claim.
